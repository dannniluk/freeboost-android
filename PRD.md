# PRD: бесплатный аналог Юбоста (рабочее название TBD)

## 1. Позиционирование

Бесплатное Android-приложение (телефон + Android TV) для доступа к YouTube без
замедления ТСПУ. Строится на DPI-обходе (ядро bye-dpi, локальный VpnService,
**ноль серверов**), а не на VPN. Прямой конкурент по задаче — Юбост
(183–229 ₽/мес), отличие: бесплатно, полная скорость канала, без аккаунтов.

База: форк ByeByeDPI (romanvht) ← ByeDPIAndroid (dovecoteescapee), ядро bye-dpi
(hufrea) + hev-socks5-tunnel. Лицензия наследуется: **GPL-3.0** (исходники
нашего форка публикуются открыто — для бесплатного продукта это норма).

## 2. Проблема надежности, которую решаем

Симптом реального пользователя (Android TV): «первые 3–5 минут все ок, потом
виснет». Причины в порядке вероятности:

| # | Причина | Решение (фикс) |
|---|---------|----------------|
| 1 | QUIC-утечка: YouTube гоняет видео по UDP/443, DPI-трюки bye-dpi — про TCP. ТСПУ читает SNI из QUIC Initial → душит поток → буфер кончается → висяк | **F1: `--quic-block`** — ядро дропает UDP/443, клиент откатывается на TCP, который трюкается |
| 2 | DNS-отравление (с 02.2026 youtube.com вычищен из НСДИ): bye-dpi шлёт плоский UDP/53 → провайдер подменяет ответы | **F2: встроенный DoH** — локальный DNS-сервер на адресе TUN, резолв через DNS-over-HTTPS (dns.google, AdGuard DoH), сокет защищён через `VpnService.protect()` |
| 3 | ТСПУ апдейтит правила, стратегии (аргументы ядра) перестают работать | **F3: автоподбор стратегии** при первом запуске + удалённо обновляемые пресеты по оператору |
| 4 | «Работало и сдохло» в середине сессии (переклассификация ТСПУ, деградация) | **F4: watchdog** — периодический health-check через прокси, деградация → автопереключение стратегии / рестарт туннеля |
| 5 | Сервис умирает на ТВ, нет самообновления | **F5: TV-режим** — автозапуск (уже есть в базе), foreground-сервис, самообновление APK, focus/D-pad UX |

## 3. Архитектура

```
[Приложения (YouTube и т.д.)]
   │  DNS → 10.10.10.10:53 (локальная доставка, НЕ в TUN)
   │         └── LocalDnsServer (Kotlin) → DoH (SSLSocket, protect()) → 8.8.8.8:443
   │  остальной трафик → TUN-интерфейс (VpnService)
   │         └── hev-socks5-tunnel (tun2socks) → SOCKS5 127.0.0.1:1080
   │                 └── bye-dpi (C-ядро): TCP-трюки (fake/disorder/oob/split)
   │                     UDP/443 → DROP (--quic-block, F1)
   │                     UDP/53  → пропускается (DNS уже перехвачен выше)
   └── Watchdog (F4): проба через SOCKS5, метрика скорости → эскалация
```

Ключевые инварианты:
- Собственный трафик приложения (DoH, watchdog-пробы) не ходит через TUN:
  DoH-сокеты — `protect()`, приложение исключено из VPN в builder.
- Режимы приложений: whitelist (только выбранные) / blacklist / все.
- Нулевая телеметрия по умолчанию (наследуем принцип базы).

## 4. Не-цели (v1)

- Не VPN: не меняем IP, не обходим гео-блоки (ChatGPT и т.п. — нет).
- Своих серверов нет вообще: инфраструктура = GitHub (releases, raw-конфиги).
- iOS/Windows — вне_scope (там нужен серверный путь, см. «Гибрид» ниже).

## 5. Гибрид (этап 2, опционально)

Бесплатное DPI-ядро (машина привлечения) + платный VPN-фолбэк на своих VPS,
включается автоматически, когда DPI на провайдере юзера не работает. Модель
Amnezia. Юридика: приём платежей = оферта + агрегатор (Prodamus/ЮKassa),
формулировки без «обхода блокировок» (КоАП 13.52 — штрафы за рекламу/популяризацию).

## 6. Дистрибуция

- GitHub Releases (universal APK + по ABI) + самообновление в приложении
- Obtainium / IzzyOnDroid — авто-обновляемые каналы
- Лендинг с зеркалами доменов (по образцу Юбоста, если начнут блокировать)
- Telegram-канал поддержки
